# Security

Please do not include Microsoft/Xbox tokens, `tokens.txt`, authentication codes, account identifiers, crash dumps containing private data, or other secrets in public issues.

For ordinary compatibility bugs, open a GitHub issue with:
- game version;
- Proton version;
- Steam packaging (native or Flatpak);
- GPU/driver;
- sanitized `CrashContext.runtime-xml`;
- relevant sanitized `xgr.log` lines.
