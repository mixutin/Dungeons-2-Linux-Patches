Minecraft Dungeons II Linux / Proton Game 1.1.2.0

Dungeons 2 Linux Patches

Unofficial Linux compatibility fixes for Minecraft Dungeons II on Steam, Proton, SteamOS and Flatpak Steam. The first release fixes a reproducible xgameruntime.dll async task-queue crash and the four-minute Microsoft authentication failure path that can leave stale UI/input state before crashing.

Download latest release

What it fixes

xgameruntime crash

Prevents an async completion from dereferencing a task queue that the game has already closed.

Microsoft auth timeout

Removes the blocking ~240 second authentication path and launches sign-in safely in the background.

Flatpak Steam

Uses XDG_DATA_HOME and stages the helper in a path visible to the Steam sandbox.

Stale UI/input symptoms

Addresses the runtime failure observed alongside stuck interaction prompts, cursor fallback and multiplayer state oddities.

Install

Download the release ZIP, extract it, close the game, then run:

chmod +x install.sh xauth.py
./install.sh

Set this Steam launch option:

WINEDLLOVERRIDES="xgameruntime=n" %command%
